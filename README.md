# salt-door-tide-entry

Deterministic Node 22 procedural image for the make.fun "Make the AI judge excited" bounty: a scarlet elevator door on a pale salt flat opens beneath a colossal glowing ocean coiling upward into a luminous ring, lifting city fragments, spray, and a lone observer into the surge.

## Run

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
```

The program writes `entry.png` to `MAKEFUN_OUTPUT_DIR` (defaults to `out`).
